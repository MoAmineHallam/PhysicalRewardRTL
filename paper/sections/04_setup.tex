\section{Experimental Setup}
\label{sec:setup}

\subsection{Design families and frozen split}

The benchmark contains streaming FIR, reverse-FIR, polynomial, recursive-filter,
and median-filter accelerators under a uniform clocked interface.  Specifications
and reference functions are generated programmatically so that each parameter
choice has an executable oracle.  The resulting domain spans
\claim{FamilyCount} families and several implementation styles, but remains
template bounded.

The held-out split was committed before the model used for the reported policy
run was trained.  Interpolation contains \claim{InterpDesignCount} unseen
parameter choices inside the training ranges.  Extrapolation contains
\claim{ExtrapDesignCount} larger or newly parameterized designs outside those
ranges.  No held-out design appears in supervised examples, policy-optimization
prompts, or proxy-training rows.

\subsection{Generation and physical evaluation}

The evaluated policies are the supervised checkpoint and the subsequent
correctness-gated policy checkpoint.  Each is sampled
\claim{SamplesPerDesign} times for every held-out design.  Evaluation uses
stimuli distinct from training, and a candidate is retained only when the oracle
accepts it on both evaluation streams.

All reported physical frequencies come from post-synthesis, placement, and
routing for the same Xilinx Zynq target and timing constraint.  Frequency is
derived from the requested period and reported worst negative slack.  The term
``timing-derived frequency'' is used because the flow does not rerun
implementation at every possible clock.  This limitation affects both policies
symmetrically.

\subsection{Endpoints and uncertainty}

The primary endpoint is penalized equal-sample frequency as defined in
Section~\ref{sec:method}.  Secondary diagnostics are conditional frequency,
oracle correctness, per-family effects, and exact perfect-selector curves.
Uncertainty intervals resample paired designs within each reported regime using
a fixed analysis seed.  They are a post-hoc uncertainty analysis of frozen
artifacts, not a preregistered hypothesis test.

\subsection{Symmetric silicon protocol}

The earlier board table compared a count-weighted supervised median against an
optimized-policy maximum and is excluded from the present quantitative claims.
The replacement protocol selects the count-weighted real-Vivado median for both
policies on the same pre-existing held-out designs.  Both members of every pair
share the same functional golden, are packed into one bitstream with a
co-resident canary, and are swept with the same clock schedule.  A board number
will enter the manuscript only after the live sweep artifact exists under the
symmetric protocol.
