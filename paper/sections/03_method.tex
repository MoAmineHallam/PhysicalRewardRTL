\section{Method}
\label{sec:method}

\subsection{Functional admissibility}

For each design specification $d$, a deterministic reference model maps an
input stream to its expected output stream.  A generated module is compiled and
simulated on held-out stimuli.  Because valid implementations may have different
pipeline depths, the oracle searches the admissible latency window and requires
exact equality after alignment.  Partial similarity earns no credit.  This gate
is the sole authority for functional correctness.

Let $C_d(m)$ denote the oracle verdict for module $m$, and let
$\widehat{F}(m)$ denote the learned frequency proxy.  The training reward is

\begin{equation}
R_d(m)=
\begin{cases}
\widehat{F}(m), & C_d(m)\text{ passes},\\
\text{zero reward}, & C_d(m)\text{ fails}.
\end{cases}
\end{equation}

The gate prevents the optimizer from purchasing predicted frequency by changing
the required computation.  Group-relative advantages update the policy, with a
KL penalty to the frozen supervised policy.  A supervised warm start is
necessary because sparse correctness from the untuned generator does not
provide a practical physical-optimization signal.

\subsection{Training proxy and reporting boundary}

The proxy predicts post-route frequency from RTL features and is clipped during
training for numerical stability.  It is neither a correctness oracle nor an
evaluation metric.  After sampling, every distinct oracle-correct candidate is
implemented by the same Vivado flow.  Candidate multiplicity in the original
sample set is retained, so deduplication cannot change policy probabilities.

For policy $p$ and design $d$, the primary endpoint is

\begin{equation}
\overline{F}_{p,d}=\frac{\sum_{m\in\mathcal{M}_{p,d}}
c_m F_{\mathrm{Vivado}}(m)}{n_d},
\end{equation}

where $c_m$ is the original multiplicity and $n_d$ is the full sampling budget.
Incorrect samples are absent from $\mathcal{M}_{p,d}$ and therefore contribute
zero; an implementation failure is explicitly assigned zero.  The headline
statistic is the mean of $\overline{F}_{p,d}$ over designs.  We report
conditional-on-correct frequency and correctness separately as diagnostics.

\subsection{Perfect-selector upper bound}

For the supervised policy we reconstruct the empirical distribution containing
both measured correct candidates and a zero-mass point for every incorrect
sample.  The expected maximum of $N$ independent draws is computed exactly from
that empirical cumulative distribution.  This selector is intentionally
unrealizable: it assumes the post-route frequency of every candidate.  It
therefore upper-bounds practical reranking at the same sampling budget and is a
conservative reference for one optimized draw.

\subsection{Fail-closed result generation}

The canonical analysis requires exactly \claim{DesignCount} distinct designs,
the frozen regime counts, both policies, and a common sample budget of
\claim{SamplesPerDesign}.  Every manifest candidate must have a corresponding
PPA row.  The script emits named TeX claims, tables, plots, a JSON result object,
and a ledger containing the computation and artifact line ranges for every
claim.  The verification program recomputes the outputs, validates every source
pointer, resolves every claim used by the manuscript, and rejects raw numeric
literals in authored prose.
