Please write a Verilog module named `priority_enc4` that implements a 4-to-2 priority encoder.

Ports:
  input  clk        - clock
  input  rst_n      - active-low synchronous reset
  input  [3:0] req  - 4-bit request input (req[3] has highest priority)
  output [1:0] enc  - 2-bit encoded output (index of highest-priority active request)
  output valid      - 1 if any req bit is set, 0 otherwise

Behavior:
  - Registered: enc and valid update on posedge clk.
  - On !rst_n: enc <= 0, valid <= 0.
  - Priority: req[3] > req[2] > req[1] > req[0].
  - enc = 3 if req[3], else 2 if req[2], else 1 if req[1], else 0 if req[0].
  - valid = |req.
