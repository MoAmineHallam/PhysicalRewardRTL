Please write a Verilog module named `shift_accum` that implements a shift-and-accumulate: each cycle adds an 4-bit input to a running 8-bit accumulator, then right-shifts the accumulator by 1.

Ports:
  input  clk         - clock
  input  rst_n       - active-low synchronous reset
  input  [3:0] data  - 4-bit unsigned input added each cycle
  output [7:0] accum - 8-bit accumulator output

Behavior:
  - Registered: accum updates on posedge clk.
  - On !rst_n: accum <= 0.
  - Each cycle: accum <= (accum + {4'b0, data}) >> 1  (add data zero-extended, then arithmetic right-shift by 1, i.e., logical shift since we treat as unsigned).
  - The >> 1 is a logical right shift (unsigned): MSB gets 0.
