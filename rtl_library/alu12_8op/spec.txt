Write a Verilog module named `alu12_8op`, a registered 12-bit ALU with 8 operations selected by op:
  op=0: result = a + b
  op=1: result = a - b
  op=2: result = a & b
  op=3: result = a | b
  op=4: result = a ^ b
  op=5: result = ~a
  op=6: result = a << 1
  op=7: result = a >> 1
Ports: clk, rst_n, [11:0] a, b, [2:0] op, [11:0] result.
