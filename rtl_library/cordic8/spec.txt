Write a Verilog module named `cordic8`, an 8-iteration rotation-mode CORDIC, with inputs `clk`, active-low `rst_n`, an 8-bit angle input `x` (units of 90 degrees = 256), and a 16-bit registered output `y`. Run 8 integer shift-add CORDIC iterations starting from x0=9949, y0=0, z0=x, with the per-iteration arctan table [128, 76, 40, 20, 10, 5, 3, 1], and register the low 16 bits of the final x into `y`. Clear `y` to 0 on `!rst_n`.
