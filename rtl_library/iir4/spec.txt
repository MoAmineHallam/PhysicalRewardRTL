Write a Verilog module named `iir4`, an order-4 IIR filter with inputs `clk`, active-low `rst_n`, an 8-bit unsigned sample input `x`, and a 16-bit registered output `y`. Each cycle compute y[n] = (sum over k=0..4 of B[k]*x[n-k]) + ((9*y[n-1])>>4) + ((5*y[n-2])>>4), keeping only the low 16 bits (mod 2^16), where the feedforward coefficients are B = [3, 5, 7, 9, 11] (B[0] applies to the current sample) and y[n-1], y[n-2] are the previous two outputs. Clear all state to 0 on `!rst_n`.
