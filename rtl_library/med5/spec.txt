Write a Verilog module named `med5`, a streaming median-of-5 filter with inputs `clk`, active-low `rst_n`, an 8-bit unsigned sample input `x`, and a 16-bit registered output `y`. Each cycle output the median of a 5-sample window consisting of the current sample `x` and the previous 4 samples (window initialised to 0), zero-extended to 16 bits. Use only comparisons (no multiplies). Clear all state to 0 on `!rst_n`.
