Please write a Verilog module named `sign_ext` that sign-extends a 4-bit two's complement value to 8 bits.

Ports:
  input  clk         - clock
  input  rst_n       - active-low synchronous reset
  input  [3:0] in4   - 4-bit two's complement input
  output [7:0] out8  - 8-bit sign-extended output

Behavior:
  - Registered: out8 updates on posedge clk.
  - On !rst_n: out8 <= 0.
  - out8 = {{4{in4[3]}}, in4}  (replicate the sign bit into the upper 4 bits).
