Please write a Verilog module named `comparator4` that compares two 4-bit unsigned numbers.

Ports:
  input  clk     - clock
  input  rst_n   - active-low synchronous reset
  input  [3:0] a - 4-bit unsigned operand
  input  [3:0] b - 4-bit unsigned operand
  output gt      - 1 if a > b, else 0
  output eq      - 1 if a == b, else 0
  output lt      - 1 if a < b, else 0

Behavior:
  - Registered: gt, eq, lt update on posedge clk.
  - On !rst_n: gt <= 0, eq <= 0, lt <= 0.
  - Exactly one of gt/eq/lt is high each cycle.
