Please write a Verilog module named `abs_val` that computes the absolute value of a 4-bit two's complement number.

Ports:
  input  clk         - clock
  input  rst_n       - active-low synchronous reset
  input  [3:0] in    - 4-bit two's complement input (-8 to +7)
  output [3:0] out   - 4-bit unsigned absolute value (0 to 8); note: |{-8}| = 8 wraps to 4'b1000

Behavior:
  - Registered: out updates on posedge clk.
  - On !rst_n: out <= 0.
  - If in[3]=1 (negative): out = (~in + 1) & 4'hF  (two's complement negation, 4-bit truncated).
  - If in[3]=0 (non-negative): out = in.
