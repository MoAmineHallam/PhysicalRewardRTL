Please write a Verilog module named `clk_div4` that generates a divided clock enable (not an actual clock) at 1/4 the input clock rate.

Ports:
  input  clk         - clock
  input  rst_n       - active-low synchronous reset
  output [1:0] cnt   - 2-bit counter (0 to 3)
  output en          - high for exactly one cycle every 4 clocks (when cnt wraps to 0)

Behavior:
  - Registered: cnt and en update on posedge clk.
  - On !rst_n: cnt <= 0, en <= 0.
  - cnt increments each clock, wrapping 3->0.
  - en is 1 exactly when cnt is about to wrap (cnt==3), i.e., en is registered output of (cnt==3).
  - So: en[t] = 1 iff cnt[t-1] == 3.
