Please write a Verilog module named `barrel_shift` that performs a logical left shift.

Ports:
  input  clk        - clock
  input  rst_n      - active-low synchronous reset
  input  [7:0] data - 8-bit input data
  input  [1:0] shamt - shift amount (0 to 3)
  output [7:0] out  - data shifted left by shamt, zero-filled

Behavior:
  - Registered: out updates on posedge clk.
  - On !rst_n: out <= 0.
  - out = data << shamt (logical left shift, low bits filled with zero,
    result truncated to 8 bits).
