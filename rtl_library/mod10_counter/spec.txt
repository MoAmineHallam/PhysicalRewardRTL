Please write a Verilog module named `mod10_counter` that implements a modulo-10 (decade) counter.

Ports:
  input  clk        - clock
  input  rst_n      - active-low synchronous reset
  output [3:0] count - 4-bit counter value (0 to 9)

Behavior:
  - Registered: count updates on posedge clk.
  - On !rst_n: count <= 0.
  - Counts 0,1,2,...,9,0,1,... wrapping at 10.
  - The module has no other inputs; it free-runs.
