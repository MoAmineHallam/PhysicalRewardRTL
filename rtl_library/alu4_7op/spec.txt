Write a Verilog module named `alu4_7op`, a registered 4-bit ALU with 7 operations selected by op:
  op=0: result = a + b
  op=1: result = a - b
  op=2: result = a & b
  op=3: result = a | b
  op=4: result = a ^ b
  op=5: result = ~a
  op=6: result = a << 1
Ports: clk, rst_n, [3:0] a, b, [2:0] op, [3:0] result.
