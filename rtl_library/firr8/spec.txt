Write a Verilog module named `firr8`, a 8-tap direct-form FIR filter with inputs `clk`, active-low `rst_n`, an 8-bit unsigned sample input `x`, and a 16-bit registered output `y`. Maintain a 8-element delay line of past samples (tap 0 = newest = current `x`). The coefficient for tap k is simply (k+1) -- there is no coefficient table; compute it from the index. Each cycle set `y` to the low 16 bits of the sum over k=0..7 of (k+1)*tap[k]. Clear all state to 0 on `!rst_n`.
