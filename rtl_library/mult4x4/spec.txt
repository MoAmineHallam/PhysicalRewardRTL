Please write a Verilog module named `mult4x4` that multiplies two 4-bit unsigned numbers.

Ports:
  input  clk           - clock
  input  rst_n         - active-low synchronous reset
  input  [3:0] a       - 4-bit unsigned operand
  input  [3:0] b       - 4-bit unsigned operand
  output [7:0] product - 8-bit unsigned product

Behavior:
  - Registered: product updates on posedge clk.
  - On !rst_n: product <= 0.
  - product = a * b (full 8-bit unsigned result).
