Write a Verilog module named `fir8_8b`, a 8-tap direct-form FIR filter with inputs `clk`, active-low `rst_n`, an 8-bit unsigned sample input `x`, and a 16-bit registered output `y`. Keep a 8-element delay line of past samples and each cycle output the low 16 bits of the sum of products of the taps with the fixed coefficients [3, 5, 7, 9, 9, 7, 5, 3]. Clear state to 0 on `!rst_n`.
