Write a Verilog module named `fir16_8b`, a 16-tap direct-form FIR filter with inputs `clk`, active-low `rst_n`, an 8-bit unsigned sample input `x`, and a 16-bit registered output `y`. Keep a 16-element delay line of past samples and each cycle output the low 16 bits of the sum of products of the taps with the fixed coefficients [3, 7, 12, 19, 27, 34, 40, 43, 43, 40, 34, 27, 19, 12, 7, 3]. Clear state to 0 on `!rst_n`.
