Please write a Verilog module named `johnson_counter` that implements a 4-bit Johnson (twisted ring) counter.

Ports:
  input  clk        - clock
  input  rst_n      - active-low synchronous reset
  output [3:0] count - 4-bit Johnson counter state

Behavior:
  - Registered: count updates on posedge clk.
  - On !rst_n: count <= 4'b0000.
  - Each cycle: count <= {count[2:0], ~count[3]}  (shift left, feed inverted MSB into LSB).
  - Sequence: 0000 -> 0001 -> 0011 -> 0111 -> 1111 -> 1110 -> 1100 -> 1000 -> 0000 -> ...
  - The module has no other inputs; it free-runs.
