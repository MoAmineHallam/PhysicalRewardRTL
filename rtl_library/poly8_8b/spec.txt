Write a Verilog module named `poly8_8b` with inputs `clk`, active-low `rst_n`, an 8-bit input `x`, and a 16-bit registered output `y`. Evaluate the degree-8 polynomial with coefficients [1, 3, 5, 7, 9, 11, 13, 15, 17] (c0 first) at `x` using Horner's method, keeping only the low 16 bits (mod 2^16), and register the result into `y`. Clear `y` to 0 on `!rst_n`.
